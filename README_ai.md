# Cluster Node Manager DataSystem (CNMD)

本readme由DeepSeek 3.2浏览自己(?)后生成。

一个为大型语言模型（LLM）设计的、安全的**交互式文件操作与管理环境**。它将一个AI智能体（Agent）的工作范围限制在指定的项目目录内，并提供了对话状态（节点）的保存、加载和管理功能，使得复杂、多步骤的文件操作任务能够被安全地分段执行和回溯。

## 核心特性

- **安全的沙箱环境**：通过系统提示词（System Prompt）严格限定AI Agent的工作目录，防止其对系统其他部分进行未经授权的访问。
- **可管理的对话上下文**：引入“节点”（Node）概念，用户可以随时保存当前的完整对话状态（包括所有消息历史），并在之后任何时间点重新加载，实现工作进度的存档与读档。
- **内置文件操作指令**：为AI Agent封装了基础的目录查看、文件读/写/删指令，使其能根据用户需求自动化处理项目文件。
- **操作日志记录**：所有与AI的交互（用户输入、AI回复、思考过程）均以JSON格式实时保存，便于审计、分析和调试。
- **命令行交互界面**：提供直观的`>>>`提示符，支持混合输入自然语言指令和特定的系统命令。

## 工作原理

1. **初始化**：程序启动时，从`config.json`读取基础工作路径，并创建一个初始对话节点（`init`）。
2. **指令分发**：
   - 用户输入以`#`开头时，被视为**系统命令**，由主程序直接处理（如节点管理、备份）。
   - 其他输入被视为**用户任务指令**，被添加到上下文中并发送给AI模型（`bot.reply`）。
3. **AI任务执行**：
   - AI根据其收到的提示词规则分析任务。
   - 若任务无需文件操作，AI直接返回结果。
   - 若任务需要文件操作，AI在其回复中嵌入格式化的`$$${指令}$$$`。主程序会解析该指令，调用对应的`tools`模块函数执行实际操作，并将结果作为下一轮对话的输入。
4. **状态持久化**：每次AI回复后，当前的完整对话记录（`messages`）都会自动保存到`./logs/{时间戳}.json`文件中。
