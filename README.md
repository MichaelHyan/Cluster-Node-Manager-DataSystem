## 📖 项目简介

CNMD 是一个创新的 Agent 型 AI 对话管理系统，旨在解决当前对话式大模型存在的核心痛点：**对话给出了不符合预期的答案，无法回退，继续对话容易被先前对话记录带偏。**

CNMD 借助类节点会话管理模式，支持对话状态的保存、加载与回退，让用户可以灵活地在不同对话分支间切换。同时，CNMD 赋予了 LLM 文件读写、终端命令执行、网络爬虫、多模态处理等 Agent 工具能力，使其能够真正完成工作任务而非仅仅对话。

**如果你需要的是一个可以辅助你进行工作，可以按照你的工作节奏走而非完全取代一个人的工作的工具，则你可以选择本项目。本项目虽具有工作流能力，但不建议滥用。**

**任何由任意 Agent/Workflow 框架产生的工作结果均需要你的审查，而不是将工作要求甩给它了事。你需要了解你的具体需求，也需为 Agent 生成结果负责。**

**如果你需要的是一个可独立进行任务的"员工"，还请使用 Harness Agent 等主流框架。**

## ✨ 核心特性

- **🔗 节点式对话管理**：支持保存、加载和回退对话状态，像 Git 分支一样管理对话走向。
- **⚡ 事件驱动模式**：LLM 可自主调用 Agent 工具链（文件操作、终端、网络），循环执行直到完成任务。
- **🧰 自定义工具能力**：允许用户自行编写工具链并由 Agent 调用。
- **🧠 记忆数据库系统**：支持对话记忆的智能提取、持久化存储、混合检索与自动整理，让 Agent 拥有长期记忆。
- **📁 文件操作能力**：提供目录浏览、文件读写、删除、备份等完整操作。
- **💻 终端命令执行**：支持 CMD / PowerShell 命令执行与结果获取。
- **🌐 网络访问能力**：内置网页抓取、Ping 检测、自定义 Header 等网络工具。
- **🖼️ 多模态支持**：支持图片、音频、视频的原生多模态处理。
- **🤖 子任务系统**：支持将复杂任务拆分为多个子任务，由独立子智能体并行执行。
- **🎯 技能模块系统**：可扩展的 Skill 模块架构，支持动态加载技能文档。
- **💬 多端接入**：支持命令行、Web UI、微信三种交互模式。
- **📝 自动日志记录**：每次会话自动创建日志并记录完整对话内容。
- **🎭 人设系统**：支持加载不同人设与人格，适应多种对话场景。

## 📌 核心概念

在开始使用之前，了解以下核心概念有助于更好地使用 CNMD。

### 事件驱动模式

不同于传统的大模型对话，事件模式下 LLM 可选择操作 Agent 工具而不直接回答用户，并等待工具返回结果后继续执行，直到完成任务。从用户下达命令到 LLM 完成命令之间的过程为一个**事件**。

如仅对话，则一次回复即为一个事件。

### 节点操作

在每次事件开始前，可存档当前对话记录，随时回退到任意节点重新开始，创建不同的对话分支进行探索：

```text
    #node save eventb
          ↓
eventA-eventB-eventC-eventD->...
(init)    |
          | -> #node load eventb
          |
       eventE->eventF->....
      (->eventB)
```

## 🚀 快速开始

### 1. 安装依赖

如你需要所有运行方式：

```bash
pip install -r requirements.txt
```

依赖包含：
- `openai` — LLM API 调用
- `flask` + `flask-socketio` — Web UI 服务，非必须
- `requests` — HTTP 请求
- `pycryptodome` — 微信文件加解密
- `qrcode` — 终端二维码显示

如你仅使用 CLI/微信 ClawBot 模式，可以不安装 Flask。

### 2. 配置

在 `config.json` 中填入你的 API 信息：

```json
{
    "API_KEY": "sk-your-api-key",
    "BASE_URL": "api-base-url",
    "MODEL": "model-name",
    "base_path": "workspace-path",
    "lang":"zh_cn",
    "break": true
}
```

| 配置项 | 说明 |
|--------|------|
| `API_KEY` | OpenAI 兼容 API 密钥 |
| `BASE_URL` | API 基础 URL（支持任何 OpenAI 兼容接口） |
| `MODEL` | 使用的模型名称 |
| `base_path` | Agent 文件操作的根目录，Agent 将视该目录为你的项目目录 |
| `lang` | Agent 工具使用的语言，目前支持中文、英文，也可自行在 `config.json` 和 `lang` 目录进行配置 |
| `break` | 重复指令处理方式，`true` 为直接中断任务，`false` 为拒绝但继续 |

你可以修改 `config_model.json` 对 OpenAI API 参数进行指定，如修改 `temperature`：

```json
{
    "temperature": 1,
    "其他参数名": "其他参数"
}
```
注：此配置仅对支持该功能的大模型生效，如 `deepseek-v3.2` 不会因 `temperature` 参数的存在调节输出。

### 3. 启动

根据需求选择启动方式：

| 模式 | 启动命令 | 说明 |
|------|---------|------|
| 命令行模式 | `python CNMD_cli.py` 或 `start_cli.bat` | 终端交互，直接输入命令 |
| Web UI 模式 | `python CNMD_webui.py` 或 `start_webui.bat` | 浏览器访问 `http://localhost:5000` |
| 微信模式 | `python CNMD_wechat.py` 或 `start_wechat.bat` | 微信扫码登录后通过微信对话 |

> 注意：直接启动 `cnmd.py` 为调试模式，虽然具有大部分功能，但不建议使用。

## 🎛️ 用户控制命令

在对话中，你可以使用以下以 `#` 开头的命令直接控制 CNMD 的行为：

| 命令 | 说明 |
|------|------|
| `#node save <名称>` | 保存当前对话状态到指定节点 |
| `#node load <名称>` | 从指定节点加载对话状态 |
| `#node list` | 列出所有已保存的节点 |
| `#node backward <轮数>` | 回退指定轮数的对话（默认1轮） |
| `#node backwardms` | 回退一次事件 |
| `#mem save` | 提取当前对话的关键信息并保存到记忆数据库 |
| `#mem analyse` | 调用 LLM 对记忆数据库进行整理、去重和压缩 |
| `#bot reasoning on/off` | 开关思考内容返回 |
| `#bot reset` | 清空对话记录 |
| `#bot reload` | 重置模型参数(API热更新) |
| `#bot prompt <预设名>` | 切换系统提示词预设（包含 persona、skills、extra 三个模块） |
| `#backup` | 备份当前工作目录 |
| `#help` | 显示帮助信息 |

## 💬 三种使用模式详解

### CLI模式

最基础的模式，在终端中直接与 CNMD 交互：

```bash
python CNMD_cli.py [预设提示词]
```

使用终端直接使用，可用于代码协助。

允许多行输入，输入指令后回车键入空字符（打两次回车）将指令传达至 CNMD，可拖拽文件将地址复制到 shell。

允许使用 `#pause` 指令强制暂停当前任务。

在CLI模式，如果仅输入python CNMD_cli.py，会启动CLI模式默认提示词，如果你有自己的自定义预设，可以在后面加入你的预设名。

### Web UI 模式

基于 Flask-SocketIO 的实时网页聊天界面，支持局域网多设备访问。

> 此模式下你需要先输入 `@bot` 来调用 Agent。

```bash
python CNMD_webui.py
```

- 访问地址：`http://localhost:5000`
- 局域网设备访问：`http://[服务器IP]:5000`
- 使用 `@bot` 前缀或 `#` 命令触发 Agent 处理。
- 支持自定义昵称和气泡颜色。
- 支持在线用户列表显示。

> ⚠️ 如 5000 端口不可用，可尝试 8000/8080/3000 端口。由于使用 HTTP 协议，浏览器可能会显示安全提醒，属于正常现象。

### 微信模式

通过微信 iLink Bot API 接入微信，实现微信内与 Agent 对话：

```bash
python CNMD_wechat.py
```

- **首次启动**：终端显示二维码，使用微信扫码登录。
- **凭证保存**：登录成功后凭证自动保存至 `wechat/credentials.json`，后续启动无需重新扫码。
- **重新登录**：删除 `wechat/credentials.json` 后重启即可。
- **支持消息类型**：文本、图片、语音（自动转文字）、文件、视频。
- **文件自动下载**：接收的图片/文件/视频自动下载至 `./files/` 目录。
- **文件发送**：Agent 可通过 `send` 指令向用户发送文件。
- **定时提醒**：Agent 可创建定时器，到时自动发送提醒消息。
- **停止回复**：发送 `#pause` 可强制终止任务。

## 🧩 技能模块系统

CNMD 内置可扩展的技能模块系统，技能文档位于 `./skills/` 目录，Agent 可根据需要动态读取并学习。

当前已有技能如下：

| 技能 | 文件 | 说明 |
|------|------|------|
| 计时器 | `timer.md` | CNMD 计时器接口规范 |
| 多模态 | `multimodal.md` | 图片/音频/视频处理接口 |
| 文件发送 | `sender.md` | 微信文件发送接口 |
| 技能创建 | `skill_creator.md` | 创建和编辑技能文档 |
| 子任务控制 | `submission.md` | 多子任务分发与执行 |
| 压缩归档 | `ziparchive.md` | 文件压缩/解压缩 |
| 天气查询 | `weather.md` | 天气与预报查询 |
| 人格提取 | `personality_create.md` | 从对话中提取人格特征 |
| 人设加载 | `personality_load.md` | 从 `./persona/` 目录加载原始人格文件 |
| 心理评估 | `psych_assessment.md` | 隐式心理状况评估 |

### 如何查看与创建技能

- **查看技能**：直接阅读 `./skills/` 目录下任意 `.md` 文件的内容即可。
- **创建技能**：
  1. 在 `./skills/` 目录下创建一个新的 `.md` 文件（例如 `my_skill.md`）。
  2. 在文件中使用清晰的自然语言，描述技能的用途、参数、使用步骤以及期望的返回格式。
  3. 在对话中告知 Agent 新技能的文件名，或在系统提示词中说明其调用方法。
- 你也可以编写 skill，或者令 Agent 自行总结当前能力并写入 skill 文档。

> **注意**：技能文档不是 `Memory.md`。如你需要将某种技能记忆存储为 skill，请确保你保存的是**技能的使用方式**，而不是历史对话内容。

## 🧠 系统提示词自定义

允许对系统提示词进行自定义，以加载不同的 Agent 人格和能力。

### 结构说明

系统提示词由三个核心模块构成，均以 Markdown 格式保存在 `prompt_loader/` 目录下：
1.  **基础人设 (persona)**：定义 Agent 的基础身份和行为准则。建议保留。
2.  **基础能力 (skills)**：定义 Agent 可使用的工具链和基础技能。建议使用默认的 `skill_base`。
3.  **特殊规则 (extra)**：根据需求定制额外的对话或工作规则。

### 配置步骤

1.  **准备文件**：在 `prompt_loader/` 目录下，分别创建或编辑 `.md` 格式的人设文件和规则文件。你可以自行编写，或使用 Agent 的 `personality_create` 技能辅助生成。
    > 提示：建议使用默认的 `skill_base` 作为基础能力文件。本项目使用自定义工具链，不支持 `tool calling` API。
2.  **编辑预设配置**：在 `prompt_loader/config.json` 中，添加一个你的预设名称及对应文件配置：
    ```json
    "[你的预设名]": {
        "persona": "[你的人设文件名，不含后缀]",
        "skills": "skill_base",
        "extra": "[你的规则文件名，不含后缀]"
    }
    ```
    > 如果不需要某个模块，可以在对应位置填写 `"none"`。
3.  **在程序中应用**：在启动脚本（如 `CNMD_cli.py`）中，找到 `cnm.set_prompt('agent_wechat')` 语句，将其改为 `cnm.set_prompt('[你的预设名]')`。

使用 `#bot prompt <预设名>` 命令可以在运行时动态切换系统提示词预设。

## 🧰 自定义工具链

你可以为 CNMD 自定义新的 Agent 工具。

1.  **编写工具程序**：可以是任何可执行程序或脚本，确保它能被调用且接受参数（可以为空参数）。
2.  **在 `tool_handler.py` 中注册**：编写调用逻辑，确保返回符合规范的 JSON 信息：
    ```json
    {
        "sys": "[如果需要，填写给 LLM 的工具返回信息]",
        "cli": "[填写给用户的可视化返回信息]"
    }
    ```
3.  **（可选）添加多语言支持**：如果希望工具支持多语言，在 `./lang/` 目录下的语言键文件中添加你的自定义键。
4.  **告知 Agent**：将工具的使用方法编写成一个 Skill 文档，或者直接在系统提示词中说明调用方式。

## 🎭 人设与人格系统

CNMD 包含两层人设机制：

### 系统提示词预设（Prompt Preset）

通过 `#bot prompt <预设名>` 命令切换的是 `prompt_loader/config.json` 中定义的**完整系统提示词预设**，包含 persona、skills、extra 三个模块的组合。详见「系统提示词自定义」章节。

### 原始人格文件（Persona Files）

`./persona/` 目录存放的是**未处理的原始人格文件**，用于：
- **人格读取**：由 `personality_load` 技能加载，作为人格蒸馏的数据源。
- **人格蒸馏输出**：`personality_create` 技能从对话中提取的人格特征会输出到此目录。

这两个模块相互配合：原始人格文件经蒸馏处理后，可以生成更精炼的 persona 文件供系统提示词使用。

## 📂 日志系统

每次会话自动创建日志文件，保存在 `./logs/` 目录下：

- `{时间戳}.json` — 完整对话记录。
- `{时间戳}_node.json` — 节点状态快照。

## 🧠 记忆数据库系统

CNMD 内置了基于 LLM 辅助的记忆数据库系统。它不同于传统的 `Memory.md`，拥有独立的向量储存区，通过 `#mem` 指令进行交互。

### 核心功能
- 使用总结将重要信息存储为记忆键，持久化保存在 `database/mem.json` 中。
- 记忆键可进行关联，关联信息保存在 `database/relate.json` 中，在记忆整理中自动生成。
- 调用时 LLM 可根据关键词自行匹配，匹配机制为 Jaccard 相似度，匹配失败则使用 LLM 进行二次匹配。
- 支持整理机制：可使用 LLM 对重复或复杂的记忆键进行化简和压缩。

### 使用指南
用户可通过以下命令手动管理记忆库：

| 命令 | 说明 |
|------|------|
| `#mem save` | 总结当前对话上下文，提取关键信息并存入记忆数据库 |
| `#mem analyse` | 对现有记忆数据库进行全局整理、去重和压缩 |

## ⚠️ 注意事项

- 使用前请在 `config.json` 中正确配置 API 信息。
- 请将 `base_path` 设置为 Agent 可操作的工作目录。
- **重要**：使用 Agent 文件操作前请做好备份，CNMD 内置 `#backup` 命令可供使用。
- 微信模式接收的文件自动保存至 `./files/` 目录。
- 本项目互联网部分使用 HTTP 协议。
