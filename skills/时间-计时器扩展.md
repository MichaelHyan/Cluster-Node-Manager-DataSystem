# 计时发送技能

本技能定义了如何在特定时间延迟发送信息。

## 📋 使用场景

### ✅ 适用情况

当满足以下条件之一时，应启用此技能：

*   **明确请求**：用户明确要求在某事件点需要执行任务。

## 🔧 接口指令

在回答内容的末尾，使用 `$$$` 作为指令块的起始和结束标记。注意：与标准文件读写指令格式相同。

### 语法格式

```text
$$$timer 指定时间戳 指令提示$$$
```

当前时间戳可用标准工具中的timeread接口获取，指令提示为指定时间进行的任务提示。

发出指令后在这个时间你会收到提示。

提示请明确目标时间点需要的任务。

### 调用示例

仅供参考，不要直接执行。

```bash
# 示例：当用户提示在5分钟后查看天气，假设当前时间戳为100
# 将时间戳加上5*60得到400
# 你应回答如下：
我将创建时间戳任务。$$$timer 400 请查看天气$$$
```
