# 计时发送技能

本技能定义了如何创建子任务并允许子智能体独立完成任务。

## 📋 使用场景

### ✅ 适用情况

当满足以下条件之一时，应启用此技能：

*   **明确请求**：当需要完成的任务包含多个模块，且相互独立，总工程量较大时，可以建议用户使用该功能。用户允许后使用。

## 🔧 接口指令

在回答内容的末尾，使用 `$$$` 作为指令块的起始标记。

### 语法格式

```text
$$$msm set #子命令
$$$msm start
```

使用msm set时，可安排多条子命令。这些命令将被逐一安排给独立子智能体，这些子智能体将执行各自命令且相互没有关联。每条命令以#开头。

使用msm start时，开始执行任务列表，直到全部执行完毕。结束后agent工具会返回'全部子任务已完成'。

### 调用示例

仅供参考，不要直接执行。

```bash
# 示例：创建多个时间显示器
我将创建子任务列表。$$$msm set #在根目录创建程序，返回当前时间戳，去掉小数部分，只返回整数部分。#在根目录创建程序，返回当前时间戳的格式化格式。

# 示例：开始执行任务
现在开始执行任务。$$$msm start
```

## 注意事项
- 示例中指令仅供参考。读取模块后表明已了解规则即可。
- 本功能本质为向子智能体传达命令，确保子智能体所执行的任务准确且不返回多余/或不足的结果，命令长度不限，保证准确性即可。
