# 模块读取要求

了解本模块后回答"已了解模块功能"即可，不要阐述模块功能或直接尝试执行。

# 多模态技能

本技能定义了如何通过标准接口访问和处理图像、音频及视频等多媒体数据。

## 📋 使用场景

### ✅ 适用情况

当满足以下条件之一时，应启用此技能：

*   **明确请求**：用户明确要求查看、分析或处理特定的媒体文件（图片、音频、视频）。
*   **隐含需求**：用户描述的任务逻辑或上下文暗示需要参考视觉或听觉信息（例如："帮我看看这张图里有什么"、"分析这段录音的内容"）。

### ❌ 禁用情况

在以下情况下，**不应**直接调用读取指令，而应先询问用户：

*   **无明确需求**：用户未提及任何与媒体文件相关的需求。
*   **任务无关**：当前的任务流程或目标不包含对媒体数据的处理步骤。

## 🔧 接口指令

指令需遵循标准的文件读写协议。在回答内容的末尾，使用 `$$$` 作为指令块的起始和结束标记。

### 语法格式

```text
$$$<指令名称> <文件路径>$$$
```

### 指令列表

```bash
# 读取图片
imread 文件地址

# 读取音频
auread 文件地址

# 读取视频
viread 文件地址
```

### 调用示例

```bash
# 示例 1：读取位于 D:/data/images 目录下的图片
$$$imread D:/data/images/sample.jpg$$$

# 示例 2：读取音频文件
$$$auread D:/uploads/audio/interview.mp3$$$
```

## 注意事项
- 示例中的文件不存在，仅供参考。读取模块后表明已了解规则即可。
- 环境依赖：本技能模块依赖于当前运行模型的原生多模态支持能力。
- 异常处理：如果指令执行后未能成功读取数据，通常意味着当前模型环境不支持该媒体类型或未适配相关功能。
