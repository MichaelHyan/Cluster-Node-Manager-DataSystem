# 模块读取要求

了解本模块后回答"已了解模块功能"即可，不要阐述模块功能或直接尝试执行。

# 计时发送技能

本技能定义了如何在特定时间延迟发送信息。

## 📋 使用场景

### ✅ 适用情况

当满足以下条件之一时，应启用此技能：

*   **明确请求**：用户明确要求在某事件点需要执行任务。

## 🔧 接口指令

在回答内容的末尾，使用 `$$$` 作为指令块的起始和结束标记。注意：与标准文件读写指令格式相同。

### 语法格式

```text
$$$send 文件路径$$$
```

## 注意事项
- 环境依赖：本技能仅在微信模式可用。
- 异常处理：如果指令执行后未能成功执行，通常意味着当前并不在微信模式。
